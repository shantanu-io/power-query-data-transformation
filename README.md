# Power Query Data Transformation

## Objective

This project demonstrates data transformation using Power Query in Power BI.

## Task 1 – Text Functions

- Converted Customer_Name to UPPERCASE
- Extracted First Name from Customer_Name
- Extracted first 3 characters from City

## Task 2 – Date Functions

- Created Year from Order_Date
- Created Month Name from Order_Date
- Created Day Name from Order_Date

## Task 3 – Number Functions

- Created Total Sales using Quantity × Unit_Price
- Created 10% Discount
- Created Final Amount after discount

## Tools Used

- Power BI
- Power Query
- Microsoft Excel

## Outcome

Successfully transformed the dataset using Power Query Text, Date and Number Functions.
